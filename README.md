# 法律研究引擎 (legal-research)

> 不帮你搜法条，帮你建立法律问题的五层分析框架。

## 新用户开箱（拿到这个包先读这里）

本包**开箱即用**——纯方法论零配置就能跑。下面三档按需取用，缺任何一档都不阻塞主流程（引擎自带降级链）。

| 档位 | 你要做什么 | 得到什么 |
|------|-----------|---------|
| **档1 纯方法论**（零配置） | 把 `legal-research/` 整个文件夹放进你 AI 工具的 skills 目录，重启 | 五层引擎跑通；法条/案例靠 AI 内置知识，标注置信度 |
| **档2 基础**（+联网核验） | 档1 + 让 AI 可用联网搜索 | 法条可核验（flk.npc.gov.cn）、案例可检索 |
| **档3 完整**（+本地库+法律数据库） | 档2 + 配置法律数据库 MCP / 建本地知识库 | retrieve_first 检索增强 + 多源交叉核验 |

**三条验证话术**（装好后逐条试）：

| 说 | 应发生 |
|---|---|
| 「查一下民法典第725条」 | 返回法条原文 + 时效标注 + 来源 |
| 「帮我研究一下建设工程价款优先受偿权」 | 走五层引擎：先视角发现（P0），再逐层分析 |
| 「简单查一下XX」 | 降级为 L1→L2→L3 常规模式 |

> 各平台 skills 目录示例：Claude Code `.claude/skills/`；Cursor `.cursor/skills/`。拷贝后确认 `legal-research/SKILL.md` 直接可见，不要多套一层目录。

### 环境断点（按此逐项确认）

本引擎有几处**需要根据你的环境配置**才能发挥全力的环节。都不装也能跑（自动降级），但建议你知晓：

| # | 断点 | 是什么 | 怎么接 | 不接会怎样 |
|---|------|--------|--------|-----------|
| 1 | **检索门禁** | 输出前强制校验法条来源的脚本（防编造硬闸） | 脚本已附带 `scripts/harness_retrieve_first.py`，把 SKILL.md 门禁段路径改成你的实际路径 | 退化为人工自查来源标注，失去硬阻塞 → 见 `references/harness-setup.md` |
| 2 | **registry.json** | 声明你接入了哪些检索源 | 复制模板 `config/search_targets/registry.json`，把已接入源改 `connected` | 用内置降级链兜底，可正常研究 |
| 3 | **本地知识库** | 你自己的案件/文章/法条语料库（检索第一优先级） | 可选增强，建库见 `references/local-kb-setup.md` | 自动从法律数据库/联网搜索起步 |

## 你什么时候用它？

- 客户丢来一个模糊法律问题，说"帮我研究一下"——从哪开始？
- 写代理词前想确认"本地法院怎么判"——翻了一小时裁判文书网还没结论？
- 对方律师提了一个你没预料到的论点——庭前才发现？

这个 skill 用五层递进法帮你**系统性地拆解任何法律问题**。不是只搜法条，是让你不遗漏。

---

## 它会交付什么？

一份结构化法律研究报告（.md），含：

| 层级 | 内容 | 触发条件 |
|------|------|---------|
| L1 概念矩阵 | 大白话问题拆成精确法律要件 | 默认 |
| L2 法规体系 | 按效力层级排列 + 口径差异 | 默认 |
| L3 裁判预判 | 按法院层级/地域分析裁判倾向 | 默认 |
| L4 反方论证 | 站在对方立场攻击自己的论证 | 深度模式 |
| L5 盲区扫描 | 扫描遗漏的请求权基础与抗辩点 | 深度模式 |

## 它怎么防 AI 编法条？

三层编码，强度递增：

```
提示词层（弱·建议）   →  Skill 层（中·规则）   →  Harness 层（硬·门禁）
"请标注来源"             SKILL.md 里的硬规则       一个独立脚本，输出前强制过闸
```

Harness 层是确定性的正则校验，不依赖模型自觉——法条引用后 80 字内无来源标注直接判 FAIL，禁止输出。接入方法见 `references/harness-setup.md`。

## 方法论来源

- **五层递进引擎**：原创，从大量法律研究实战中沉淀
- **P0 视角发现**：灵感来自 Stanford OVAL Lab STORM (NAACL 2024, arXiv:2402.14207)——多样化视角 → 多样化问题 → 多样化检索结果
- **案例效力分级**：依据最高法《关于统一法律适用加强类案检索的指导意见（试行）》

## 目录结构

```
legal-research/
├── SKILL.md                          # 路由层（AI 加载入口）
├── references/
│   ├── five-layer-engine.md          # 五层引擎完整执行流程
│   ├── perspective-discovery.md      # P0 视角发现方法论
│   ├── citation-rules.md             # 法条引用与案例效力规则
│   ├── harness-setup.md              # 检索门禁接入指引
│   └── local-kb-setup.md             # 本地知识库建库指引（可选）
├── scripts/
│   ├── harness_retrieve_first.py     # 检索门禁脚本（纯标准库）
│   ├── validate-legal-citation.mjs   # 报告引用格式校验（Node）
│   ├── tag_documents.py              # 本地库摄入（PDF/MD/TXT 打标入库）
│   ├── ingest.py                     # PDF 判决书摄入
│   ├── index_to_sqlite.py            # SQLite FTS 索引
│   ├── rag_ask.py                    # 本地库检索（向量+FTS 双路召回）
│   └── embed_index.py                # 向量索引构建（可选 bge-m3）
├── config/
│   └── search_targets/
│       └── registry.json             # 检索源注册表模板
└── evals/
    └── gt-cases/                     # 评测基准示例
```
