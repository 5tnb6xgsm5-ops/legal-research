# 检索门禁接入指引（Harness 层）

> 面向：刚拿到本包的新用户。
> 读完你能回答三个问题：**门禁是什么 → 我要不要装 → 不装怎么办**。

---

## 一、门禁是什么

legal-research 的法条防幻觉是**三层编码**，强度递增：

```
提示词层（弱·建议）   →  Skill 层（中·规则）   →  Harness 层（硬·门禁）
"请标注来源"             SKILL.md 里的硬规则       一个独立脚本，输出前强制过闸
```

Harness 层是最后一道闸。它干一件事：**法律回答输出前，用法条正则扫一遍草稿，凡是「裸法条无来源标注」的直接判 FAIL，禁止输出**。

| 判定 | 含义 | 动作 |
|------|------|------|
| ✅ PASS | 引用都带来源标注 | 直接输出 |
| ⚠️ WARN | 长回答通篇无来源 / 有推断性表述 | 可输出，但需向用户注明 |
| 🚫 FAIL | 法条引用后 80 字内无 `[来源]` 标注 | **禁止输出**，回退检索后重写 |

**它为什么必要**：提示词层和 Skill 层都是"劝 AI 自觉"，模型长上下文下会漂移。Harness 层是确定性的正则校验，不依赖模型自觉——这是"防编造"从软约束变硬约束的关键一跳。

## 二、我要不要装

**一句话：本包已附带脚本，你唯一要做的，是让 SKILL.md 知道它在哪。**

脚本位置：`scripts/harness_retrieve_first.py`（纯标准库，零依赖，Python 3.9+ 即可）。

### 接入两步

**第 1 步：确认脚本能跑**

```bash
python3 scripts/harness_retrieve_first.py --help
```

能打印用法即正常。

**第 2 步：让 SKILL.md 指向它**

打开 `SKILL.md`，找到「检索门禁」一节的**门禁脚本路径**，改成你的实际绝对路径。三种写法任选：

| 写法 | 适用 | 示例 |
|------|------|------|
| 包内相对路径（推荐） | 脚本随包分发，位置固定 | `scripts/harness_retrieve_first.py` |
| 绝对路径 | 脚本放在了包外固定位置 | `/Users/你/skills/legal-research/scripts/harness_retrieve_first.py` |
| 环境变量 | 多机同步、路径常变 | `$LEGAL_RESEARCH_HOME/scripts/harness_retrieve_first.py` |

改完后，SKILL.md 里这条门禁流程就能跑了：

```bash
echo "$草稿" | python3 scripts/harness_retrieve_first.py --check-stdin --question "$用户问题"
# 退出码 0=PASS，1=FAIL/WARN
```

### 接入方式（让门禁成为固定步骤）

门禁不是靠你手动跑——是在 skill 提示词里写死一条规则：**AI 每次输出法律结论前，先把草稿交给门禁脚本检查**。本包 `SKILL.md` 的「检索门禁」一节已内置这条规则，你改对路径后即自动生效。

## 三、不装怎么办（手动降级出口）

门禁是增强，不是前提。不想装 / 暂时没有 Python 环境时，按下面的规则**手动降级**，依然守住"不编造"底线：

1. SKILL.md 「法条引用规则」全部照常遵守（来源优先级、时效标注、禁止行为清单）——这些本就不依赖脚本。
2. 每次输出前**自查一遍**：凡是「《XX法》第X条」后面，80 字内必须有 `[来源·已核实]` 标注；没有就补上或删掉。
3. 所有来源都没检索到 → 直接标 `[CITE NEEDED]`，**不输出具体法条内容**。

> ⚠️ 降级是有代价的：手动自查依赖你的注意力，长报告容易漏。条件允许就装上门禁脚本——它一分钟就能接好。

## 四、门禁脚本工作原理（想自己改/自己写的看这里）

脚本是纯确定性的正则校验，核心逻辑三步：

```
1. 裸法条扫描   用正则匹配「民法典第807条」「建工解释一第36条」这类引用
                （兼容：单条 / 顿号并列 / 区间「至」/ 中文数字编号）
2. 来源邻近检查  在每个法条命中点前后 80 字窗口内，找是否有合法来源标注
                （合法标注清单与 SKILL.md「来源优先级」对齐：[本地KB·已核实] 等 15 种）
3. 分级判定      裸法条无来源 → FAIL；长回答无来源 → WARN；推断表述无出处 → WARN
```

退出码 `0=PASS / 1=FAIL或WARN`，方便接入 CI 或其他管线。

### 想自己实现一个？

脚本只有 ~150 行、纯标准库。最小可用版本只需覆盖两点：① 一个法条引用正则；② 一个"邻近窗口内找来源标注"的函数。完整实现直接读 `scripts/harness_retrieve_first.py` 即可，注释齐全。你要改的一般只有两处：`VALID_CITES`（合法来源标注清单）和 `LAW_NAME`（覆盖的法律名称）——按你的业务领域增删。

## 五、常见问题

| 问题 | 解法 |
|------|------|
| `--help` 报 `python3: command not found` | 装 Python 3.9+；或改用你 AI 环境自带的 Python 解释器路径 |
| 门禁把我正确的法条判成 FAIL | 检查来源标注写法是否在 `VALID_CITES` 清单里（必须是 `[北大法宝·已核实]` 这种完整格式，`[北大法宝]` 少了 `·已核实` 不认） |
| 想让门禁更松/更严 | 改脚本里 `_has_cite_near` 的 `window`（默认 80 字）和 `VALID_CITES` 清单 |
| 门禁 FAIL 后脚本让我跑 `rag_ask.py` | 那是接本地知识库的回退动作；没建本地库就忽略，改用 MCP/WebSearch 检索后重写 |
